# King Wa Tam, PhD

A PhD-trained researcher with over a decade of expertise in epidemiology, statistics,
health economics, and quantitative social science. Author of a dozen peer-reviewed
publications in leading international journals.

## Personal website

Everything lives on **[kingwatam.github.io](https://kingwatam.github.io)**:

- [Research themes](https://kingwatam.github.io#research): Biostatistics, Cancer
  Epidemiology, Ageing & Multimorbidity, Health-Economic Modelling & Policy
- [Publications](https://kingwatam.github.io/publications): 12 papers with DOIs
- [MOOC certificates](https://kingwatam.github.io/certificates): 35 courses and
  specializations, viewable as embedded PDFs
- [Projects](https://kingwatam.github.io#projects): dashboards, browser extensions, and
  this site, developed with agentic AI coding tools

## This repository

Source code for the site, built with [Astro](https://astro.build) as a fully static
build. Content lives as JSON in [`src/data`](src/data), styled with vanilla CSS using a
Swiss typographic system. No tracking, no client-side frameworks.
